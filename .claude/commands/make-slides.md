---
description: 문서를 입력받아 report-reader → structure-planner → slide-writer → ppt-builder 순서로 자동 실행하여 pptx 파일까지 완성합니다.
---

사용자가 제공한 문서/자료($ARGUMENTS)를 바탕으로 아래 4개의 서브에이전트를 반드시 이 순서대로, 각 단계의 출력을 다음 단계의 입력으로 넘기며 순차 실행하세요. 중간에 사용자에게 되묻지 말고 끝까지 자동으로 진행하세요.

1. **report-reader** 에이전트를 호출해 입력 문서에서 핵심 요약(불릿 5~10개)을 추출합니다.
2. 1번의 출력(핵심 요약)을 그대로 **structure-planner** 에이전트에 전달해 슬라이드 배치 계획(6~10장)을 세웁니다.
3. 2번의 출력(슬라이드 배치 계획)을 그대로 **slide-writer** 에이전트에 전달해 슬라이드별 실제 문구(제목 + 본문 불릿)를 작성합니다.
4. 3번의 출력(슬라이드별 문구)을 그대로 **ppt-builder** 에이전트에 전달해 실제 .pptx 파일을 outputs 폴더에 생성합니다.

각 단계가 끝나면 다음 단계로 자동으로 넘어가고, 마지막에 ppt-builder의 완성 여부와 저장 경로를 사용자에게 요약해서 보고하세요.
